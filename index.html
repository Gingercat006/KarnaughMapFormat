Pick 1 / 0 / X and click cells to fill them; drag to fill several. Clicking the same value again clears it. You can also select a cell and type 1 0 X, and move with the arrow keys. Pick a colored pen and use Loop to drag from one cell to another. Draw wrap-around groups as separate loops. With Manual corner numbers, any repeated number turns red.
